# 灵鉴 Agent MVP 产品说明

## 一、产品定位

灵鉴 Agent 是面向交付伙伴能力运营和项目伙伴匹配场景的 AI 智能体。它通过归集伙伴档案、项目案例、交付物和能力标签，形成伙伴能力画像，并根据项目需求推荐合适伙伴。

## 二、核心用户

- 一线销售
- 交付经理
- 服务伙伴运营人员
- 项目方案人员

## 三、核心流程

1. 上传或维护伙伴资料
2. 录入伙伴案例和交付物
3. AI 生成伙伴能力画像
4. 用户输入项目需求
5. Agent 推荐合适伙伴
6. 展示推荐理由、证据链和风险提示

## 四、第一期页面

### 1. Agent 工作台

用户输入自然语言项目需求，系统返回推荐伙伴、匹配度、推荐理由、支撑案例、支撑交付物和风险提示。

### 2. 伙伴资料管理

维护伙伴基础信息、能力标签、服务区域、行业经验、案例、交付物等。

### 3. 伙伴画像详情页

展示伙伴能力画像、优势领域、代表案例、交付物、风险缺口和 AI 摘要。

## 五、第一期不做

- 复杂权限
- 审核流
- 多租户
- 生产部署
- Docker
- Kubernetes
- PostgreSQL
- Redis

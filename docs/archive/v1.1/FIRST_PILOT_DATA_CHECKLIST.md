# 首批真实资源数据验收清单

状态：**DATA-01 / DATA-02 = BLOCKED - BUSINESS DATA REQUIRED**。
本轮未收到业务批准的试点资源清单。pytest / Playwright 的合成资源仅用于工程验证，不能作为正式资源或业务验收结果。

| 必需输入 | 业务方应提交的内容 | 当前状态 |
|---|---|---|
| 试点能力方向 | 至少 1 个方向、目标要求、对应现有正式能力标签 | 待业务负责人提供 |
| 目标试点伙伴 | 至少 1 家有效伙伴、负责人、参训岗位/人数/基础 | 待提供 |
| 课程清单 | 可实际使用的课程及下表元数据 | 待提供 |
| 实验清单 | 可实际使用的实验及下表元数据；不能用课程替代缺失实验 | 待提供 |
| 共享案例清单 | 既有 case_id、有效贡献伙伴及实际角色、独立共享版本、脱敏与授权记录 | 待提供 |
| 可走通路径 | 至少一条课程 + 实验 + 已授权共享案例路径，目标、投入与约束相符 | 待业务试走 |
| 资源缺口 | 缺课程/实验/案例、条件未知、替代路径和待确认负责人 | 待提供 |

每个资源逐条填写并签审：

| 字段 | 必须确认的内容 |
|---|---|
| 名称、类型、版本 | 可识别名称；course/lab/case；当前发布版本 |
| 能力映射 | 现有正式能力标签；本次目标要求 |
| 适用岗位与难度 | 不以伙伴公司画像代替参训人员基础 |
| 先修条件、预计投入 | 所需基础、时长、每周安排及是否适合试点周期 |
| 语言、站点、网络 | 可访问语言/站点、网络限制；未知明确标注 |
| 账号、环境、费用 | 账号权限、实验环境、费用/预算及生效条件 |
| 来源 | 获准来源平台与实际链接；人工检查日期及结果 |
| 人工核验 | 核验人、时间、内容/链接检查结论；仅元数据不是已学习证明 |
| 系统权限 | 是否允许内部系统可见 |
| 模型权限 | 是否允许发送至指定配置模型；与系统可见独立审批 |
| 外发权限 | 是否允许伙伴外发；与其他两维分别审批 |
| 案例授权 | 脱敏共享正文、授权范围/版本、撤销责任人；内部证据不直接共享 |

签审分别记录：资源运营负责人（真实性/链接/元数据）、业务负责人（路径适配/缺口）、产品负责人（固定样例可读性与业务判断）。

固定样例评审表应记录：同伙伴数据库迁移 / Agent 应用交付的目标能力与允许资源集合、证据不足、非培训限制、未知条件、缺失实验、显式假设、失败调整保留已确认版本。工程 mock 通过不能代替人工评审。

结论分开签署：软件工程验收 / 真实模型受控兼容性 / 首批资源数据可用性 / 真实业务试点。当前禁止宣布真实业务上线。

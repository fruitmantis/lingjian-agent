## 统计与更新规则

- 需求分布、活跃伙伴和推荐次数使用同一组符合时间、行业、区域、能力筛选且关联任务未归档的需求画像。没有需求画像的历史任务不进入该组统计，后续在第四批核对。
- 推荐次数按伙伴 ID 计算，同一任务重复出现同一伙伴只计一次。旧记录仅有名称时，仅在名称能唯一对应现有伙伴时计入；更名伙伴优先通过 ID 识别。
- 伙伴总量、画像数量和正式标签分布保持全库口径；活跃占比为筛选范围内被推荐的现有伙伴数除以全库伙伴数。供给覆盖只计算启用伙伴，并按真实 ID 去重。
- 画像提取只更新非空且类型有效的字段；能力值还须属于启用的正式标签。未通过校验的字段保留原值，人工仍可通过现有编辑接口清空。
- 机会完整度使用客户名称、项目名称、行业、区域、项目阶段、业务需求六个字段。空字符串、空白和“未识别”均算缺失；六项完整为 100%。初次抽取和后续编辑共用规则。
- 编辑机会继续保留原有部分更新语义：未提供或为 null 的字段不修改，空字符串可以清空。技术需求和原始 AI 补充建议等只读字段不随完整度计算改写，也不新增模型调用。

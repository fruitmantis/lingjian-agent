# 能力发展 current 简化验证

日期：2026-09-25。范围：当前 main 的能力发展版本流程简化；未提交、未推送、未部署。

## 实现

- 保留 Plan / Run / Version、不可变历史快照和 current。生成/修改成功仍通过既有事务更新 current；失败、超时、中断和保存回滚保留上一成功版本。没有改写存储机制、并发锁、submission 幂等或基于版本的冲突校验。
- confirmed_version_id 的 schema、外键和已有值不删除、不迁移、不清空。能力发展读写及 API 输出不再使用该指针，原 POST /development/plans/{id}/confirm 停用（404）；历史外键仍保留完整性保护。
- 任务列表/侧栏只显示生成中、已生成、生成失败、已归档。生成中允许继续查看旧 current；失败但仍有 current 时保持已生成，失败原因在详情及运行记录查看。任务筛选同步采用该状态，不把仍有结果的方案列入生成失败。
- 详情移除确认/采用动作和草稿、尚未确认、已采用等展示。历史版本保留，标记当前版本或历史版本；查看历史不会移动 current。
- 伙伴可传递视图读取 current，继续实时重检来源授权和外发字段白名单。预览返回 version_id，复制校验该 ID 仍等于 current；旧预览在版本更新后不能复制。撤权内容仍隐藏，不回退到旧 confirmed。
- API 中任务执行细节仍保留 Run 历史；没有增加表、迁移、模型场景或外部服务。本轮未访问真实模型。

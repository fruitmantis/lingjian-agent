## 本轮发现及最小修正

1. 分页测试夹具只拦截直连 `:8000`，遗漏现有同源 `/api`。仅修改 `frontend/e2e/pagination.spec.ts` 的拦截与路径归一化，两项分页用例复验通过；正式应用无改动。
2. 私有部署脚本以 root 原子写入 dotenv 后改变了文件归属，及 Caddy 所在父目录初始不允许应用用户遍历。两次失败均恢复旧配置与原服务，未回滚或覆盖数据库；修正文件归属和目录组权限后成功切换。原 `NoNewPrivileges` 保留。
3. 新 release 原本不存在 `public` 目录，复制被忽略的字体目录时丢失一层 `fonts`，真实公网浏览器检测到两份字体 404。补齐原目录层级、校验字体摘要，仅重启 ARM 前端后复验通过；字体仍不提交 Git。

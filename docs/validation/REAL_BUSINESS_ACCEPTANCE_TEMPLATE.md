# 伴飞 Agent 真实业务验收模板

空白模板，不代表已验收。本模板只用于业务评审记录，不是新的产品表单或日常流程门槛。能力发展实际输入仍为 **目标伙伴 + 自然语言方向**；不要求预先填写人数、周期、预算、个人基础或人工差距确认才能使用。

## 人工评审要点

- 能力方向、伙伴可复用基础与推荐理由是否符合真实情况？
- 是否误读伙伴资料、错误声称未经确认的能力不足？
- 推荐伙伴/资源、难度、先修及访问条件是否合适？unknown 与限制是否明确？
- 发展建议是否有业务逻辑？局部问答是否简洁、调整是否落实用户意图？
- 项目机会是否保留已知信息、缺失标未知，而不是编造字段？
- 伙伴可传递内容是否可理解，是否包含内部证据、备注或未授权信息？

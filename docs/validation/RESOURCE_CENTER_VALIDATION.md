## 实现与兼容边界

- 分类复用 app_metadata 的 enablement_resource_categories 配置；初始化 7 个岗位和 4 个专区，后台可新增、改名、排序。版本元数据保存岗位/专区 ID 数组；筛选用 EXISTS，不联表展开资源行，跨分类仍是同一个 resource_id。分类改名不改写既有发布快照。
- 课程/实验统一基础、进阶两层级；前台按岗位/专区浏览，保留搜索。卡片只展示标题、简介、分类、层级；实验另显示时长，课程不显示；详情和录入使用对应精简字段。封面采用可选外部图片链接，使用已有安全 URL 校验，不新增附件管理或上传流程。
- 新录入契约拒绝旧费用、语言、站点、来源平台、成组账号环境条件、旧难度、目标能力/技术方向及人工能力标签字段。课程/实验 review 路由停用，服务层也拒绝调用；发布不再读取或要求人工核验记录，案例原规则不变。
- 未发现当前课程/实验存在实际播放器、报名、学习进度、教材包、评价/评分、免费名额或实验人次模块；没有为清理不存在的功能新增实现。案例仍使用的旧筛选/展示代码限定在案例分支。
- enablement_resources、enablement_resource_versions、草稿、发布指针、用途权限、撤权、跳转审计保留。没有删除表、旧核验行、能力映射或历史资源/方案快照。旧字段仅在历史元数据只读适配中使用：原入门→基础，原进阶/高级→进阶，未知不推断；下一次发布须明确层级。旧目标能力映射为课程/实验目标，旧先修文本仅作为实验基本要求兼容读取。未分类资源仍可从全部及搜索找到，不自动猜测分类。
- AI 候选使用名称、简介、岗位、专区、层级、课程目标/大纲、实验目标；分类仅辅助相关性，不要求同岗/同专区。新资源没有正式能力标签也能进入候选；既有有效标签继续作内部信号，失效标签不再使课程/实验整体消失。模型与来源跳转的 URL 隔离、资源 ID/版本/权限校验继续保留。
- 已保存的能力发展 Version 不重写，读取时按原引用重检权限并投影精简元数据；失败/撤权行为、解释不新建 Version、明确修改才创建 Version 保持。历史请求约束字段和旧分析难度字段只作兼容，不恢复编辑流程。
- 归档的 SQLite v12 Pilot 接收/导入工具不是当前 PostgreSQL 资源录入入口；不得用于运行库。新课程/实验由本轮精简 API/后台维护，不恢复历史 Pilot 的课程核验流程。

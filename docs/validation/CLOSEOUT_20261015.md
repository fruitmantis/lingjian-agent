## WSL 更新和实际范围

用户单独授权后，沿正式目录的 `enablement-dev.sh stop/start/status` 更新 HTTP80 站点，未运行 init。更新前后匹配、发展、原生文件及贡献在途数均为 0；3000/8000 仅回环，80 为入口。

WSL 实际 IP 的健康、首页、管理员资料页面和当前路由 JS 均返回 200；新卡片异常提示、目录轮询、文件来源状态代码及后端响应字段已加载。未认证的目录 API 仍返回 401。Windows 对实际 IP 的健康/资料页面及 localhost 健康均为 200。

数据库只读摘要比对中，除用户活动字段外各表一致，用户其他字段一致；模型配置及私有环境文件摘要一致。本轮更新和收口付费模型调用为 0，未上传、提炼、合并、重试正式文件或改写正式业务数据。

当前工具没有可连接的正常登录浏览器，未声称在正式数据下现场点击验证失败卡片。该显示行为已由独立隔离 QA 验收，部署后已核对真实入口与加载代码；管理员可在原登录会话中打开资料目录补做现场观察，无需制造错误或付费调用。

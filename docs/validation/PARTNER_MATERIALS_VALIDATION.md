## 数据与权限

schema 17 增量字段位于 partners、cases、partner_documents、deliverables。删除旧 case_share_configs / case_share_versions / enablement_reviews；课程实验的草稿/发布版本与 Plan/Run/Version 不变。迁移前私有完整备份，事务内校验业务行数不变；不同的旧共享正文另存既有审计，原案例原文与全部文件保留。旧分类不猜测。带内部附件或不同原文的旧案例默认关闭展示，需要管理员主动选择。

伙伴资料、原始画像和完整当前画像仅管理员读取。普通案例目录、详情和每个文件端点都检查 visible 与伙伴 active，隐藏后旧 URL 无权访问。历史任务内容仍可读，文件链接检查当前状态。

原件完整保存；图片、图片替代文本及扫描内容不进入画像文本。预览失败与文字提取结果分别保存。上传、重试采用现有后台执行；重启时未完成处理转失败，可手动重试。无静默截断；手动画像输入超过明确预算或资料仍处理失败时拒绝生成，保留旧画像。

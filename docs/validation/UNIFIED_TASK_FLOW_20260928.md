## 实施范围

- 项目找伙伴：理解中判断范围并一次提取事实，第二次结合伙伴资料匹配、输出答复并判断供给。需求画像、项目机会、待采纳标签建议复用这些事实；技术失败不再生成规则画像冒充成功。
- 能力发展：理解、按需检索、最终答复。解释、比较和重申使用一次理解答复，不创建新版本。追问带当前要求、正文、按展示顺序的资源及最近三组完整问答。
- 局部修改只应用授权条目标识和正文片段的补丁，未涉及内容原样保留；成功后创建新 Version/current，失败保留旧版。沿用权限、引用、幂等、版本冲突和失败保护。
- 同一任务重试仅在要求、资料、权限及配置未变化时复用理解；不跨任务缓存。理解快照复用 Run.input_snapshot，匹配快照复用 app_metadata；不改变旧版本或推荐记录格式。
- 一次运行固定模型和参数。停用、删除或修改配置后，未发出的后续调用停止；新运行使用启用的场景首选或明确的系统默认，不选择任意第一个模型。
- 页面显示最终顾问答复与资源卡片。AGENTS.md、README.md 已同步，不再要求独立 Scope Gate 或阶段间重新路由。
